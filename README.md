Fortune Cookie Wisdom for Developers: one original fortune-cookie line for a software developer. The deploy that scares you most is the one that teaches you what your tests were too polite to say.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (plain text, 99 characters plus a newline, pure Python standard library, deterministic — same bytes every run).
